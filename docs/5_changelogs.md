# Changelogs

## Version 0.1 - March 2026

Initial release of MitoDate.

### Features

- FASTA sequence processing (rename and split modes)
- BEAST XML configuration file generation
- Bayesian phylogenetic analysis using BEAST 1.10.4
- Result parsing and summarization
- Multiple and single-sample dating modes
- DNA substitution models (HKY, GTR)
- SkyGrid population model
- Strict molecular clock
- User-defined priors
- Containerized execution (Docker/Singularity)
- Hardware acceleration (BEAGLE library)
- Selective sample rerunning capability
