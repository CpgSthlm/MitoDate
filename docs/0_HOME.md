# MitoDate - Home

## Welcome to MitoDate Documentation

MitoDate is a Nextflow pipeline designed to date mitochondrial DNA (mtDNA) sequences using BEAST (Bayesian Evolutionary Analysis by Sampling Trees). The pipeline automates the following processes:

- Processing and preparing FASTA sequence alignments
- Generating BEAST XML configuration files with customizable evolutionary models
- Running Bayesian phylogenetic inference using BEAST
- Parsing and collecting results from BEAST analyses
- Supporting both single and multiple sample dating approaches
